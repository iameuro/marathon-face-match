# Marathon Face Match

Static marketing-style running content site with:
- face match experience
- foot-profile shoe recommendation
- athlete detail pages
- brand pages
- guide pages
- bilingual-ready structure

## Quick start

### Option 1: Open locally
Open `index.html` in your browser.

### Option 2: Run with VS Code Live Server
- Open this folder in VS Code
- Install the Live Server extension
- Right click `index.html`
- Click `Open with Live Server`

### Option 3: Simple local server
```bash
python3 -m http.server 8000
```

Then open:
```bash
http://localhost:8000
```
